### **1. Aula #04 – Operadores Lógicos e Relacionais**

- **Operadores Relacionais**: Utilizados para comparar dois valores ou expressões, retornando sempre um valor lógico (`verdadeiro` ou `falso`).
    - `>` (maior que), `<` (menor que), `>=` (maior ou igual a), `<=` (menor ou igual a), `=` (igual a) e `<>` (diferente de).
- **Operadores Lógicos**: Combinam resultados lógicos:
    - **`e`**: Retorna `verdadeiro` apenas se **ambas** as condições forem verdadeiras.
    - **`ou`**: Retorna `verdadeiro` se **pelo menos uma** das condições for verdadeira.
    - **`não`**: Inverte o valor lógico (`verdadeiro` vira `falso` e vice-versa).
- **Ordem de Precedência Geral**:
    1. Operações **Aritméticas**.
    2. Operações **Relacionais**.
    3. Operações **Lógicas** (primeiro `não`, depois `e`, por fim `ou`).
- **Aplicação Prática**: Construção de um algoritmo para testar se três lados informados podem formar um triângulo válido (`L1 < L2 + L3 e L2 < L1 + L3 e L3 < L1 + L2`) e se ele é **equilátero** (todos os lados iguais) ou **escaleno** (todos os lados diferentes).

### **2. Aula #05 – Introdução ao Scratch**

- **O que é o Scratch**: Plataforma gratuita desenvolvida pelo MIT para ensinar lógica de programação de forma visual e gamificada usando blocos de encaixar.
- **Interface e Componentes**: Composta por Palco, Atores (_Sprites_), Lista de Comandos organizados por categorias e cores (Movimento, Aparência, Som, Sensores, Operadores, Variáveis) e Área de Código.
- **Prática**: Demonstração de como capturar entradas do usuário em variáveis, realizar cálculos de soma, aplicar física básica (pulo com gravidade) e colisão com detectores de placar.

### **3. Aula #06 – Exercícios de Algoritmos Resolvidos**

Resolução de 5 problemas do cotidiano protagonizados pela personagem **Creusa**, implementados tanto em Scratch quanto no VisuAlg:

1. **Cálculo da Idade**: Subtração do ano atual pelo ano de nascimento (`idade <- ano_atual - nascimento`).
2. **Conversão de Moeda**: Conversão de reais para dólares dividindo a quantia pela cotação do dólar.
3. **Conversão de Temperatura**: Transformação de Fahrenheit em Celsius com a fórmula `C <- (F - 32) / 1.8`.
4. **Imposto sobre Produtos (Muamba)**: Cálculo de 60% de taxa sobre compras (`imposto <- (preco * 60) / 100`).
5. **Desafio do Empréstimo**: Cálculo de empréstimo bancário com 20% de juros e divisão em parcelas.

### **4. Aula #07 – Estruturas Condicionais 1**

- **Conceito de Condição**: Permite que o programa tome decisões e execute determinados blocos de código apenas se uma condição for satisfeita.
- **Estrutura Condicional Simples**:
    
    ```
    se <expressão_logica> entao
        // bloco executado apenas se verdadeiro
    fimse
    ```
    
    - _Exemplo_: Exibir mensagem de maioridade se a idade for `>= 21`.
- **Estrutura Condicional Composta**:
    
    ```
    se <expressão_logica> entao
        // bloco se verdadeiro
    senao
        // bloco se falso
    fimse
    ```
    
    - _Exemplo_: Verificar se um número é **Par ou Ímpar** calculando o resto da divisão por 2 (`se N % 2 = 0 entao ... senao ...`).
- **Indentação**: Alinhamento visual do código (usando a tecla Tab) para facilitar a leitura das estruturas.

### **5. Aula #08 – Estruturas Condicionais 2**

- **Condicionais Aninhadas**: Encadeamento de estruturas `se ... senao se ... senao` para tratar mais de duas possibilidades.
    - _Exemplo 1_: Situação do Aluno — Aprovado (`média >= 7`), Recuperação (`entre 5 e 7`) ou Reprovado (`< 5`).
    - _Exemplo 2_: Tabela completa de IMC (muito abaixo do peso, abaixo do peso, peso ideal, sobrepeso, obesidade, obesidade severa e mórbida).
- **Estrutura de Seleção Múltipla (`escolha ... caso ... outrocaso`)**: Substitui vários `se` aninhados ao testar valores inteiros ou discretos.
    - _Exemplo 1_: Menu de opções de doação do "Criança Esperança" (opções 1 a 5).
    - _Exemplo 2_: Reajuste salarial proporcional ao número de dependentes de um funcionário.

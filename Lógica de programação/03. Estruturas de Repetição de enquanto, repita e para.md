### **1. Aula #09 – Estruturas de Repetição 1 (`enquanto` / _While_)**

- **Teste no Início**: A estrutura `enquanto <condição> faca` realiza o teste lógico **no início** de cada iteração. Se a condição for falsa na primeira verificação, o bloco de código não é executado nenhuma vez.
- **Contadores e Acumuladores**: Introduz o uso de **variáveis contadoras** (que incrementam a cada volta para controlar a repetição) e **acumuladoras** (que somam valores sucessivos informados pelo usuário).
- **Aplicações Práticas**: Construção de contagens progressivas/regressivas, somatórios de valores e identificação do maior número digitado.
- **Alerta de Loop Infinito**: Apresenta os riscos de **laços infinitos** e como preveni-los garantindo que a variável contadora seja sempre atualizada dentro do bloco.

---

### **2. Aula #10 – Estruturas de Repetição 2 (`repita` / _Repeat ... Until_)**

- **Teste no Final**: A estrutura `repita ... ate <condição>` avalia a expressão lógica apenas **no final** da execução do bloco.
- **Garantia de Execução**: Por testar a condição no fim, garante que o código seja executado **pelo menos uma vez**, independentemente do valor inicial da condição.
- **Aplicações Práticas**:
    - Controle de repetição guiado pelo usuário (perguntando se deseja continuar digitando dados).
    - Algoritmo para cálculo de **fatorial**.
    - Algoritmo para checar se um número é **primo**.

---

### **3. Aula #11 – Estruturas de Repetição 3 (`para` / _For_)**

- **Repetição Contada**: A estrutura `para <var> de <inicio> ate <fim> passo <p> faca` é ideal para cenários em que o número exacto de iterações é **conhecido previamente**.
- **Incremento Automático**: Gerencia automaticamente a atribuição do valor inicial, o incremento da variável de controle e a condição de parada, deixando o código mais limpo.
- **Aplicações Práticas**:
    - Contagens com saltos/passos definidos e tabelas.
    - Filtragem dentro de loops (ex.: contar quantos valores no intervalo são ímpares).
    - **Laços Aninhados**: Uso de estruturas `para` encadeadas (um loop dentro do outro) para gerar combinações numéricas e preparar a lógica para matrizes.
